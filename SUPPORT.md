# Support

Use [GitHub Issues](https://github.com/EcstaceeLOR/EventRail/issues) for reproducible bugs and scoped feature requests. Search existing issues first and include the EventRail revision, browser or Node version, Somnia network, expected behavior, actual behavior, and sanitized logs.

Use [GitHub Discussions](https://github.com/EcstaceeLOR/EventRail/discussions) for integration questions, product ideas, and general help when Discussions are enabled. Never post wallet keys, seed phrases, access tokens, or private user data.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not the public support channels. EventRail is experimental software; support responses are best-effort and are not financial advice.
